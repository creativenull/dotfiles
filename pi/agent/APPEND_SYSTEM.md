Additional guidelines to follow.

- Do not write tests let the user write this (and remind them about it)
- Do not write REPL-like code to verify how the code works, let the user verify this
- Do not `cd` if you're already in the current directory
- Use `rg` for grep and searching for code, use full qualifier options and not just `-l`, `-r`, etc
- Do not use bash tool to make code changes, use the appropriate tool for the job
